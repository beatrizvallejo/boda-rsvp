---
description: Genera un mensaje listo para enviar al compañero de devops con las preguntas abiertas
---

1. Lee `docs/devops-preguntas.md` y `docs/produccion.md`.
2. Redacta un único mensaje en español, directo y técnico, apto para Slack o email:
   - **Contexto:** 2–3 líneas sobre qué es la web y en qué punto está.
   - **Preguntas abiertas:** numeradas con su id (P01…). Cada una con la pregunta, la recomendación y qué bloquea.
   - **Petición final:** que responda indicando el id de cada pregunta.
3. Muéstralo para copiar. No modifiques ningún archivo.
